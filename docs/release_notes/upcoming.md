# Upcoming release — черновик

Сюда складываем пункты, которые войдут в следующий релиз. Перед релизом переносим в `X-Y-Z.md` и очищаем этот файл.

## EN
### Highlights
- **Bring your own sing-box core.** Click the version on the Home screen and pick a sing-box binary: the launcher verifies it (runnable, right architecture, actually sing-box, and able to parse your current config), installs it atomically, and reports the version it actually installed. A rejected file leaves your working core untouched — byte for byte.
- **Import a subscription from a file.** Subscriptions → Add Subscription → **Import from File…** reads a local JSON, YAML or node-list file through the same parser a provider fetch uses. The imported source is a self-contained snapshot: it keeps working after you delete or move the original file, and it is never sent to the network, so it can never produce a provider error you did not cause.
- **Imported sources say what they are.** The row shows "Imported from <file>" instead of an empty URL, the edit screen omits the URL field and states that Refresh is not available for a file, and Update All skips them entirely. A missing core banner now offers **Load Core…** instead of only pointing at a folder.
- **A real visual redesign, not a re-skin.** The launcher now has its own application theme (light and dark palettes, macOS-like greys, #007AFF accent) instead of Fyne's defaults — which is why earlier layout work still looked like a stock toolkit. Every standard control inherits it.
- **Flat navigation.** The sidebar is one level of grouped items (Home / Network / Tools, About pinned at the bottom) with a soft rounded highlight on the selected item. The tree — and the admin-panel accent bar — are gone; detail navigation moved into the pages themselves.
- **A Home dashboard.** Instead of a proxy list beside a service panel, the app opens on a summary: connection state and the Start/Stop action, core and config details, and cards that lead to Proxies, Remote and Traffic. The proxy list gets the full page width where it belongs.
- **Content is no longer stretched edge to edge.** Pages keep a readable column (860 units, centred on wide windows) instead of cards spanning the whole display.
- **Settings and Diagnostics are grouped by meaning** into cards rather than a long form divided by rules; destructive actions are set apart.

### Technical / Internal
- SPEC 145. `ui/design.Theme` implements `fyne.Theme` with explicit light/dark palettes and the app's radii; `Font()`/`Icon()` delegate to the default theme (swapping fonts would break metrics on Windows/Linux). Installed from `main.go` — `core/uiservice` is L2 and must not import `ui/` (L7), so the stock `SetTheme` call there was removed rather than left to overwrite it.
- `RouteID` separates presentation routes from business domains: `selectSection` runs only when the domain actually changes, so Home → Proxies → Traffic neither re-applies scope/transport nor re-polls.
- New primitives: `MaxWidthLayout` (constrains and centres content, never its `MinSize`), `Card`/`ClickableCard`/`CardRow`, `SegmentedNav`, `StatusBadge`, primary/secondary/ghost/icon actions, `tintResource` (recolours `currentColor` SVGs so one icon serves normal and selected states).
- Navigation semantics preserved mechanically: the entire body of `app.tabs.OnSelected` moved verbatim into `App.selectSection` (`ui/navigation.go`). The sidebar and the retained (now off-screen) `AppTabs` both call that single method, so there is exactly one implementation of scope → panel activation → transport → refresh, in the original order.
- Pages are constructed once and swapped through a content host, so switching sections keeps scroll position, field contents and expanded sections.
- Collapsed sidebar parents keep the selected highlight while their child is active, and clicking a parent only expands it — it never changes the page.
- The core status indicator moved from the emoji tab title (▶️/⏸️) to a sidebar footer that projects `AppController.RunningState` — no second copy of the state.
- All sizes are Fyne logical units. No `canvas.Scale()`, no Retina multiplier, no `runtime.GOOS` branch for DPI, and `FYNE_SCALE` is never set.
- `docs/ARCHITECTURE.md` updated (L6/L7 rows, VpnStateChanged subscriber).
- Custom core import (`backend/service/core_import.go`) is a validate → stage → probe → atomic-rename transaction: nothing opens the destination for writing until the candidate is fully verified, so every failure path leaves the installed core byte-identical. The architecture check is Mach-O via `debug/macho` (fat slice or thin), never the `file` command; `CoreImportSupported()` reports false off macOS so the capability block stays honest. A successful swap invalidates the three binary-derived caches — `installedCoreVersionCache` does not self-expire on mtime, so without this the UI would keep reporting the old version for the rest of the session.
- Local subscription import (`backend/service/subscription_import.go`) reuses `DecodeSubscriptionContent` → `MaterializeSubscriptionBody`, i.e. exactly the pipeline a network refresh runs; only the byte source differs, and parsing happens before the state lock is taken so a large file cannot stall a concurrent refresh. The source is persisted as `kind: subscription` with `input_kind: local_snapshot` and an empty URL.
- `SubscriptionInputKind` / `state.CanRefreshSubscription` is the single source of truth for refreshability. Every fetch path (manual refresh, Update All, auto-update, warm-up) asks it instead of testing `url != ""`, which would have sent local snapshots to the network with an empty URL. Legacy records with no `input_kind` read as `remote`, so no migration is required. `state.SourceLabel` fixes two message sites that printed an empty URL as the source's name.
- New protocol methods `import_core_file` / `import_subscription_file` with capabilities `core_import` / `local_subscription_import`; `SubscriptionDTO` gained `input_kind`, `can_refresh`, `filename`. Swift budgets are explicit (45 s / 30 s) and well above the backend's additive worst case, because a timeout that fires mid-swap would report failure for a swap that succeeded. `docs/IMPORT_FLOW_AUDIT.md` records what is verified by test, by IPC and by reading only.

## RU
### Основное
- **Своё ядро sing-box.** Клик по версии на главном экране — и выбираешь бинарь sing-box: лаунчер проверяет его (запускается, верная архитектура, действительно sing-box, умеет прочитать текущий конфиг), ставит атомарно и показывает ту версию, которая реально установилась. Отклонённый файл не трогает рабочее ядро — побайтово.
- **Импорт подписки из файла.** Подписки → Add Subscription → **Import from File…** читает локальный JSON, YAML или список ссылок тем же парсером, что и загрузка от провайдера. Импортированный источник — самодостаточный снимок: он продолжает работать после удаления или переноса исходного файла и никогда не уходит в сеть, поэтому не может породить ошибку провайдера, которой не было.
- **Импортированные источники говорят, что они такое.** В строке — «Imported from <file>» вместо пустого URL, на экране правки нет поля URL и прямо сказано, что Refresh для файла недоступен, а Update All их пропускает. Баннер «ядро не найдено» теперь предлагает **Load Core…**, а не только папку.
- **Настоящий визуальный редизайн, а не перекраска.** У лаунчера появилась своя тема приложения (светлая и тёмная палитры, macOS-подобные серые, акцент #007AFF) вместо дефолтной Fyne — именно поэтому прошлые правки вёрстки всё равно выглядели как «стандартный тулкит». Тема наследуется всеми стандартными контролами.
- **Плоская навигация.** Сайдбар — один уровень пунктов, сгруппированных заголовками (Главная / Сеть / Инструменты, «О программе» прижат внизу), выбранный пункт подсвечен мягкой скруглённой заливкой. Дерево и полоса-индикатор в стиле админки убраны; детализация переехала на сами страницы.
- **Дашборд на главной.** Вместо списка узлов рядом со служебной панелью приложение открывается сводкой: состояние и кнопка Start/Stop, сведения о ядре и конфиге, карточки-переходы к Прокси, Remote и Трафику. Список узлов получает всю ширину страницы, где он и нужен.
- **Контент больше не растянут от края до края.** Страницы держат читаемую колонку (860 units, по центру на широком окне) вместо карточек на весь экран.
- **Настройки и Диагностика сгруппированы по смыслу** в карточки, а не в длинную форму с линиями; опасные действия вынесены отдельно.

### Техническое / Внутреннее
- SPEC 144. Новый пакет `ui/design`: `metrics.go` (4-й ритм отступов, радиусы, геометрия сайдбара, доли сплита, размеры окна), `typography.go` (пять уровней текста), `colors.go` (semantic-цвета из активной темы), `sidebar.go`, `page.go` (PageHeader, SectionCard, StatusBadge).
- Семантика навигации сохранена механически: тело `app.tabs.OnSelected` целиком переехало в `App.selectSection` (`ui/navigation.go`). Сайдбар и оставленный (уже невидимый) `AppTabs` зовут один и тот же метод, поэтому реализация «область → активация панели → транспорт → refresh» ровно одна и в исходном порядке.
- Страницы создаются один раз и подменяются через content host: переключение разделов сохраняет позицию скролла, введённый текст и раскрытые секции.
- Свёрнутый родитель в сайдбаре сохраняет подсветку, пока активен его подпункт; клик по родителю только разворачивает его и никогда не меняет страницу.
- Индикатор состояния ядра переехал из emoji-заголовка вкладки (▶️/⏸️) в нижнюю строку сайдбара и проецирует `AppController.RunningState` — второй копии состояния нет.
- Все размеры — в Fyne logical units. Без `canvas.Scale()`, без множителя Retina, без ветвлений по `runtime.GOOS` для DPI; `FYNE_SCALE` не выставляется.
- Обновлён `docs/ARCHITECTURE.md` (строки L6/L7, подписчик VpnStateChanged).
- Импорт ядра (`backend/service/core_import.go`) — транзакция «проверить → подготовить → прощупать → атомарный rename»: до полной проверки кандидата пункт назначения не открывается на запись, поэтому любая ошибка оставляет установленное ядро побайтово тем же. Проверка архитектуры — через `debug/macho` (fat-срез или thin), без команды `file`; `CoreImportSupported()` возвращает false вне macOS, чтобы блок capability не обещал лишнего. Успешная замена сбрасывает все три кэша, производных от бинаря: `installedCoreVersionCache` не истекает по mtime, и без сброса UI показывал бы старую версию до конца сессии.
- Импорт подписки из файла (`backend/service/subscription_import.go`) переиспользует `DecodeSubscriptionContent` → `MaterializeSubscriptionBody`, то есть ровно тот же конвейер, что и сетевой fetch; отличается только источник байт, а разбор идёт до взятия блокировки состояния, чтобы большой файл не тормозил параллельный refresh. Источник сохраняется как `kind: subscription` с `input_kind: local_snapshot` и пустым URL.
- `SubscriptionInputKind` / `state.CanRefreshSubscription` — единственный источник правды о refresheability. Все пути fetch (ручной Refresh, Update All, автообновление, прогрев) спрашивают его, а не проверяют `url != ""`: иначе локальный снимок ушёл бы в сеть с пустым URL. Legacy-записи без `input_kind` читаются как `remote`, миграция не нужна. `state.SourceLabel` чинит два места, где в сообщение подставлялся пустой URL вместо имени источника.
- Новые методы протокола `import_core_file` / `import_subscription_file` и capability `core_import` / `local_subscription_import`; в `SubscriptionDTO` добавлены `input_kind`, `can_refresh`, `filename`. Таймауты на стороне Swift заданы явно (45 с / 30 с) и с запасом над суммарным худшим случаем бэкенда: сработавший посреди замены таймаут сообщил бы об ошибке там, где замена прошла. `docs/IMPORT_FLOW_AUDIT.md` фиксирует, что подтверждено тестом, что — IPC, а что — только чтением кода.
